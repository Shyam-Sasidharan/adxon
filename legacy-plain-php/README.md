# Adxon Website and CMS

Premium PHP landing page and lightweight JSON CMS for Adxon.

## Run

Place this folder at `C:\xampp\htdocs\Adxon`, start Apache in XAMPP, then open:

- Website: `http://localhost/Adxon/`
- CMS: `http://localhost/Adxon/admin/`

Default CMS login:

- Username: `admin`
- Password: `adxon@123`

## CMS Sections

- Dashboard
- Services
- Packages
- Portfolio
- Testimonials
- Blogs
- Enquiries
- Settings and SEO

Content is stored in `data/content.json` and is created automatically on first load.
